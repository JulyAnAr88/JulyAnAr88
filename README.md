I'm **Julián**, a Data Analyst and Mathematics Teacher. I'm currently doing a **Master's degree in Data Science** (Maestría en Ciencia de Datos, UADER + UNLu) and I also work as a **Data Analyst**, where I build ETL pipelines, semantic layers and dashboards on tools like **Apache Superset, Grafana, Pentaho, Qlik, Metabase and Databricks**.
